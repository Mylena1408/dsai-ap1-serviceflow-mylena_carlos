 5. COMO USAR (novidades de 31/10)
-------------------------------------------------------------------------------

1) Documentos exigidos: em /admin > Servicos, cada servico tem o painel
   "Documentos exigidos" (ate 5; PDF/DOCX/TXT; obrigatorio ou opcional).
   O solicitante ve a lista no detalhe do servico e anexa um arquivo por
   documento (ate 2 MiB cada, 4 MiB no total).

2) Para ENVIAR documentos de verdade e preciso configurar o Supabase Storage:
     .env.local       DOCUMENT_STORAGE_URL / _BUCKET / _SECRET_KEY
     .env.test.local  TEST_DOCUMENT_STORAGE_URL / _BUCKET / _SECRET_KEY
   (chave sb_secret_ exclusiva; bucket de teste terminando em -test;
    NUNCA versionar esses arquivos)
   Depois:
     npm run storage:provision          (bucket de desenvolvimento)
     npm run storage:provision -- test  (bucket de teste)
     npm run test:integration           (passa a rodar o teste real)

3) Testes E2E nao precisam de Supabase: o playwright.config.ts liga
   TEST_DOCUMENT_STORAGE=memory, aceito so fora de producao e com banco
   terminado em _test.
